This section documents the preparation of the forensic lab environment.

A Windows 10 virtual machine was created using VMware to simulate a corporate workstation. 
A normal user account was configured to represent an employee system.

This phase also includes preparation of sensitive data used later in the investigation. 
The confidential files were created as part of the lab environment setup and existed on the system before the simulated attack activity began.


- Windows 10 installation
- User account creation
- Initial system readiness
- Presence of confidential files before the incident
- Confidential folder created with files
